## Research Execution Rules

1. **Use ALL available tools simultaneously** — Tavily search, Tavily research, Tavily crawl, VS Code web search, Context7
2. **Run 5+ parallel searches per topic** — different angles, different keywords
3. **Follow links** — don't just read snippets, extract full pages
4. **Cross-reference** — every finding needs 2+ sources
5. **Version-lock** — note exact versions, dates, and compatibility
6. **Document failures** — what you searched for but couldn't find matters too
7. **Be skeptical** — AI blog spam is rampant. Prioritize GitHub repos with stars, official docs, and known experts
